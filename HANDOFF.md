# Handoff

The full session handoff (state of every step, local setup, gotchas, what to do next) is in
[`replica/HANDOFF.md`](replica/HANDOFF.md). Read that file first.

It lives in `replica/` because it names the app this project was rebuilt from, and the rebrand sweep
(`.claude/skills/replica-brand/sweep.py`) skips the `replica/` planning folder by design. Nothing in this root file may
name it, so the whole-repo sweep stays clean.
